This is a Three.js tutorial project recreating a Minecraft clone.

Tutorial from Dan Greenheck's YouTube channel: https://www.youtube.com/@DanGreenheck/videos
See the Youtube Playlist: https://www.youtube.com/playlist?list=PLtzt35QOXmkKALLv9RzT8oGwN5qwmRjTo

Run the project with:
```
npm run dev
```

Build the project with:
```
npm run build
```
